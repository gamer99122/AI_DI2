**程式碼片段：**
```csharp
// ✅ 解決方案 1：透過建構函數注入介面

}
```

**運行輸出：**
```
使用 DI 的優點：

✅ 3. 易測試：可以注入 Mock 物件

✅ 5. 符合 SOLID 原則
```
