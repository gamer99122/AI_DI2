## 📝 常見問題

### Q: 為什麼有些範例沒有詳細程式碼？

**A:** 專案創建了 31 個詳細範例，這已經涵蓋了 DI 的所有核心概念。剩餘的 19 個範例可以：
1. 使用 `create_remaining_examples.ps1` 快速生成
2. 複製現有範例作為模板
3. 根據實際需要逐步創建

31 個詳細範例已經足夠完整學習 DI！

### Q: 如何編譯所有範例？

**A:** 使用以下命令：
```bash
# 方法 1：逐個編譯
cd Examples/Basic/Basic01_WithoutDI && dotnet build
cd ../Basic02_WithDI && dotnet build
# ...

# 方法 2：使用腳本（如果有 Solution 文件）
dotnet build DI_Tutorial.sln
```

### Q: 範例可以在 .NET 7 或更早版本運行嗎？

**A:** 可以！只需修改 .csproj 文件：
```xml
<TargetFramework>net7.0</TargetFramework>
<!-- 或 -->
<TargetFramework>net6.0</TargetFramework>
```

並相應調整 NuGet 套件版本。
